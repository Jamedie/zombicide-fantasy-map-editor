# Sources des visuels

Les 84 faces de tuiles présentes dans `assets/tiles/` proviennent de la page communautaire suivante :

- [Fantasy Tiles — Zombicide Wiki / Fandom](https://zombicide.fandom.com/wiki/Fantasy_Tiles)
- Consultation et récupération : 17 juillet 2026
- Fichiers locaux : versions WebP redimensionnées à 600 px

La page Fandom indique que le contenu communautaire est disponible sous licence CC BY-SA sauf mention contraire. Les illustrations et éléments graphiques originaux de Zombicide peuvent toutefois rester protégés par les droits de leurs ayants droit respectifs, notamment CMON. Leur présence dans ce projet est destinée à un usage local et personnel de création de cartes. Ne pas redistribuer les visuels sans vérifier les droits applicables.

Le code de l’éditeur reste distinct de ces ressources graphiques.
